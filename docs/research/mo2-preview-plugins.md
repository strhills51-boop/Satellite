# Предпросмотр файлов в MO2: что уже сделано в плагинах и что взял Satellite

Исследование 2026-11-16. Источники — страницы плагинов на Nexus и открытые репозитории; код чужих плагинов в
Satellite не переносился, только идеи и публичные описания форматов.

## Плагины и инструменты

| Что | Где | Что умеет | Как |
|---|---|---|---|
| DDS Preview (встроен в MO2) | MO2 `plugins/DDSPreview.py` | двойной клик по DDS в «Конфликтах» / дереве данных: картинка, каналы R/G/B/A, цвет фона | Python + Qt, OpenGL |
| DDS Preview Zoom and Pan | Nexus SSE 149747 | колесо — масштаб, перетаскивание — сдвиг, «вписать»; масштаб и сдвиг сохраняются при переходе между конфликтующими копиями | правка DDSPreview.py |
| Preview NIF (GabonZ, затем форк «Parapets») | Nexus SSE 69813, 137741 | 3D-просмотр NIF двойным кликом, в т. ч. из BSA (MO2 2.5.2+); `.bto` / `.btr`; NiAlphaProperty (тест и смешивание), Z-буфер, кубкарты, FaceGen (`BSDynamicTriShape`), оттенок кожи и волос, флаг Hidden, базовый PBR, анимация деревьев (альфа вершин); текстуры: свободные из модов → BSA модов → BSA игры | C++: nifly (NIF), GLI (текстуры), шейдеры по образцу NifSkope |
| MO2 Audio Player | Nexus SSE 101872 | проигрывает `wav`, `xwm`, `fuz` (и из BSA, 1.0.3) | Python + внешние конвертеры (Yakitori Audio Converter, BmlFuzTools) |
| hkxPoser, io_anim_hkx | GitHub opparco | просмотр поз и анимаций HKX, импорт в Blender | Havok SDK / hkdump |
| PyNifly | GitHub BadDogSkyrim | импорт / экспорт NIF и HKX в Blender; свой разбор packfile и сплайнового сжатия Havok (GPL-3) | Python |
| Show Animation Command NG | Nexus SSE 104356 | в игре: какие анимации сейчас играет актёр и откуда файл | SKSE |

Анимации внутри MO2 никто не показывает: hkxPoser и Blender — отдельные программы. Звук `xwm` / `fuz` плагин
проигрывает только через внешние конвертеры.

## Что взял Satellite (проводник, только чтение)

- **Картинки** (DDS Preview + Zoom and Pan): масштаб колесом к курсору, перетаскивание, «вписать» (двойной клик) и 1:1;
  каналы RGB / R / G / B / A / RGBA, фон — шахматка, тёмный, светлый; масштаб, сдвиг и канал сохраняются при переключении
  копий файла.
- **Меши** (Preview NIF): 3D прямо в предпросмотре — узлы сцены с их преобразованиями, `BSTriShape`,
  `BSSubIndexTriShape`, `BSDynamicTriShape` (лица FaceGen), скинированные меши SSE (вершины в `NiSkinPartition`), LE —
  `NiTriShape` / `NiTriStrips`; диффузная текстура из набора текстур или эффект-шейдера; порядок поиска текстуры — как у
  плагина: копия сборки (кого берёт игра: свободная или в BSA мода), иначе `Data` игры и её архивы; альфа-тест; каркас;
  вписать двойным кликом. Fallout 4 — геометрия есть, текстуры — через `.bgsm` (пока не читаются).
- **Анимации** (чего в MO2 нет): HKX Skyrim LE / SE и Fallout 4 проигрываются на скелете — скелет ищется в папке актёра
  (`…/character assets*/skeleton.hkx`, сборка, иначе игра); сплайновое и несжатое хранение, аддитивные анимации, события
  на шкале времени, пауза, кадр, скорость. Декодер сверен с PyNifly на 26 файлах: отличия ≤ 5·10⁻⁵. На скелет
  надевается тело (тело, руки, ноги, голова), а броня или тело проигрывают любую анимацию сборки — скиннинг по костям и
  весам меша (SSE / FO4 — веса в вершинах, LE — в `NiSkinData`).
- **Звук** (Audio Player): WAV, Ogg, MP3, FLAC проигрываются в браузере.

## Чего пока нет

- `xwm` и звук внутри `fuz` — это xWMA (WMA): браузер его не играет, свой декодер WMA — большая работа; плагин MO2
  решает это внешним конвертером, Satellite внешних программ не запускает.
- Освещение NifSkope / PBR, кубкарты, оттенки кожи и волос, вершинная анимация деревьев, флаг Hidden.
- Текстуры Fallout 4 через материалы `.bgsm` / `.bgem`; меши Starfield (внешние `.mesh`).
