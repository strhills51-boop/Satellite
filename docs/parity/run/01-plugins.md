# Паритет пробега: плагины (монолит CP9 + v611)

Источник: `docs/semantic/monolith/05-run.md` §4.6 (CP9), S11 §2 (`parsePluginHeaderFromFile` 100666), `resolvePluginType`
100529 / `resolvePluginTypeV503` 172032.

| Монолит | NG | Статус |
|---|---|---|
| Только корневые `.esp/.esm/.esl` loose (не из архивов) | анализатор `plugins`: `origin loose ∧ depth 0 ∧ ext ∈ esp/esm/esl` | совпадает |
| TES4: ESM `0x1`, ESL `0x200`, `MAST/CNAM/SNAM/HEDR`, `XXXX` | `sat-formats::plugin::read_plugin_header` | совпадает (проверено на реальном ESL сборки владельца: HEDR 140 = 103 записи + 37 групп) |
| Скан записей v611: 24-байтные заголовки, стек GRUP, `TES4` не считается, ссылки = REFR + ACHR | `scan_records` → `RecordCounts` (`--records`, настройка штампа анализатора) | совпадает по счёту; статусы `partial/unavailable` монолита = `error` в `PluginFacts` |
| Тип `resolvePluginType` (`espfe`, `unknown`) | `monolith_plugin_type` — дословно, для паритетных видов и импорта | совпадает |
| ESM-флаг на `.esp` → `esp` (расширение раньше флага) | `PluginHeader::kind` → `Esm` | **сознательное расхождение**: игра грузит такой плагин вместе с мастерами; для подсчёта лимитов и порядка важен класс загрузки |
| Сбой чтения → запись `recordScanStatus 'error'`, пробег продолжается | политика `optional`: ошибка в `PluginFacts.error` и в `issues` пробега, остальное у мода цело | совпадает |
| Дедуп по нормализованному пути (первый выигрывает) | корневые имена уникальны в папке (NTFS без учёта регистра) | не нужен |

## Список плагинов (монолит V527: `buildPluginMetaIndexFresh` 75 702, `applyPluginOverwriteVersions` 76 091, `calculateMo2PluginIndexes` 75 594, цвета 76 997)

NG: `sat-core::plugins` (`@sat:plugins.list`), в сессии `@sat:session.plugins`, в отчёте `sat-cli analyze` — поле `plugins`.

| Монолит | NG | Статус |
|---|---|---|
| Записи из `loadorder.txt`, `plugins.txt` (`*` = отмечен), скана; состояния enabled / disabled / implicit | `Listed::{Enabled, Disabled, Implicit, Unlisted}` | совпадает; `Unlisted` — найден в моде, менеджер ещё не видел |
| Базовые мастера Skyrim (5 шт.) — всегда активны, синие | `SKYRIM_BASE`, `Origin::Base`, `Colour::Blue` | совпадает (пакет игры — позже) |
| Creation Club `cc*.es[lmp]` в `loadorder.txt` без отметки — неявно активен | `Origin::CreationClub`, `Listed::Implicit` | совпадает |
| **Версии**: одно имя в нескольких модах; победитель — включённый владелец с наибольшим приоритетом, иначе наибольший среди всех; факты (мастера, флаги) — от победителя | `PluginVersions` (факты) + выбор победителя на каждый пересчёт по приоритетам | совпадает; победитель следует за каждым перемещением и переключением мода (тест сессии) |
| Вложенные плагины (не в корне мода) игнорируются | анализатор берёт только корень | совпадает |
| Владелец выключен → «чёрный / несуществующий», запись сохраняется | `present = false`, факты заголовка сохранены, индекса нет, `Colour::Black`; зависимые видят его недостающим мастером | совпадает; формулировка владельца: «полноценный плагин, просто выключен» |
| Найден сканом, не в списках → активен (v278) | `Unlisted` + активен, если владелец включён | совпадает |
| Индексы: полные `00…`, лёгкие `FE:000…`, в порядке загрузки, переполнение > `FD` / > `FFF` | `RuntimeIndex`, `overflow()` | совпадает |
| Хвост вне `loadorder.txt` — по приоритету владельца, затем имя | так же | совпадает |
| Недостающий мастер: нет записи, «несуществующий» или `enabled === false` | мастер не активен | совпадает |
| Цвета: синий база → чёрный → красный (мастера) → жёлтый (переполнение) → белый (скан, не загружен) → зелёный | `Colour` в том же порядке | совпадает |
| Чёрный список имён | — | позже (декорация списка плагинов) |
| Режимы сортировки (порядок загрузки / индекс / цвет) | порядок загрузки; остальное — виды | позже (виды ADR 0009) |
