# S20 — строки 171 453–173 827 (Analysis Orchestrator v503: CP9–CP12)

> Проход 1, главный курсор + курсоры связей. Монолит: `index.html` (копия `monolith.html`), строки 171 453–173 827.

## 1. Обзор

Сегмент — последние пять модулей v503 «Analysis Orchestrator» в конце главного `<script>`: хвост **CP8** (потоковые
агрегаты по моду: размеры, расширения, точные счётчики v602, топология путей v607, теги по детекторам, стикеры),
**CP9** (анализатор корневых физических плагинов: разбор TES4, скан заголовков записей v641, легаси-форма
`pluginsByModName`), **CP10** (потоковый сбор «путь → владельцы» и финализатор: победители, точные цепочки с «зубами»,
точные/производные маршрутные группы, контексты union-find), **CP11** (эфемерная проекция ядра для окна пробега — это
**живой вход «Бездны»**, его вызывает cutover) и **CP12** (синхронный регрессионный самотест cutover и публичный
`ModlistToolAnalysisCutoverV503`). Каждый модуль — v527-владелец `create…RuntimeOwnerV527().install…V503()`,
вызываемый сразу; каждый публикует `window.ModlistTool…V503` (API), инспектор и Promise самотеста.
Главная находка: в живом пробеге cutover передаёт `authoritativeConflictFinalizerOnly: true` (v508), поэтому
**потоковый финализатор конфликтов CP10 в производстве выключен** — его алгоритм живёт только в самотестах и
ручных теневых пробегах; живыми остаются CP8, CP9, CP11 (+ CP15 DDS VRAM, подключаемый cutover-ом).

### 172041–172131 — сканер заголовков записей v641 (CP9; копия `scanPluginRecordHeadersV611`, 22792)
- `normalizePluginRecordSignatureCountsLocalV641`: ключи upper-case, только `/^[A-Z0-9_]{4}$/`, счётчик конечный ≥0 → `trunc`, нули выбрасываются, сортировка по сигнатуре.
- `scanPluginRecordHeadersLocalV641(buf)`: заголовок записи 24 байта (формат Skyrim/FO4). < 24 байт → `status 'error'`. Цикл от смещения 0: снимает закрытые группы (`offset === groupEnd`), `parentEnd` = конец текущей GRUP или файла; `offset > parentEnd` → partial «crossed GRUP boundary»; сигнатура не `[A-Z0-9_]{4}` → partial. `GRUP`: `groupSize = u32@+4` (включает заголовок), `groupSize<24` или выход за parent/файл → partial; `groupHeaderCount++`, push конца, шаг 24 (внутрь группы). Иначе запись: `dataSize=u32@+4`, `next = offset+24+dataSize`, выход за границы → partial; **`TES4` не считается**, остальные — `counts[sig]++`, `recordHeaderCount++`. В конце: незакрытые группы → partial; хвост байтов → partial «Trailing N bytes». `referenceRecordCount` = REFR + ACHR. Возврат `{status, error, recordHeaderCount, groupHeaderCount, recordSignatureCounts, referenceRecordCount, referenceRecordSignatureCounts, scannedBytes, totalBytes}`; исключение → `status 'error'`.
- Используется только фолбэк-парсером (172220); живой путь идёт через легаси-парсер, который зовёт глобальный `scanPluginRecordHeadersV611` (100759). Сравнение `diff`: тела совпадают с точностью до форматирования и имён констант.

### 172897–173030 — `finalizeV503()`: алгоритм финализатора конфликтов (CP10)

  3. `shared-route-edge` — тот же победитель и ≥ 1 общее ребро.

- **Контексты:** union-find по цепочкам; все цепочки, где встречается один и тот же мод, объединяются (`union` → корень = лексикографически меньший id).
