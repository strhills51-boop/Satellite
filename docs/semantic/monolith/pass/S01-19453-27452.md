# S01 · строки 19 453–27 452 — начало главного `<script>`

Главный курсор: прочитано подряд 19 453–27 471 (до середины `BUILTIN_TAG_DETECTORS`). Курсоры связей: `xref chunk` + `xref sym`
по 30+ именам, точечные чтения 162 960–163 040, 42 460–42 546, 188 736–188 744.

## 1. Обзор

Сегмент открывает главный `<script>` (19 453) и состоит из пяти слоёв. (а) Три v527-владельца системного разделителя
PLUGINS. Это **реализации**, хотя стоят в начале файла: глобальные функции-делегаты и переназначения `renderAll` / `renderClassic` /
`parseModlist` / `importProjectObject` / `isSystemSeparator` / `getSeparatorMeta` к ним стоят на 162 963–163 033. (б) Базовые константы проекта
(ключи автосохранения и IDB, константы идентичности v459–v474, граф связей v469), debug gate, утилиты `nowIso` / `deepClone` / `uid` / `clamp`,
санитизация снимка, сброс runtime после восстановления, `createRunBucket` (форма `project.runs`). (в) Основная часть, ~6 000 строк,
**v599–v639 «сводка метрик анализа»** `project.runs.metrics`: схема v2, словарное сжатие кортежей, поколения (projectId+runId),
печать (FNV-1a digest), допуск при импорте, инвалидация и списание сущностей, терминальные состояния, контракт тип/scope, и
**все экстракторы фактов по моду** (ядро, плагины и сканер записей ESP, счётчики расширений, состав, распределение расширений,
топология путей, форма пакета, презентация). (г) Константы системных разделителей Skyrim / Overwrite, `els`, `palette`,
`startWizard`, мобильный мост PHONE V2 (CP9–CP22). (д) Глобальный `const state` (27 036) и начало таблицы `BUILTIN_TAG_DETECTORS`.

2. Ключи сущностей: `mod:<id>`, `separator:<id>`, `project:<id>`, `logicalGroup:<id>`. Составной мод — `mod:composite-mod:<groupId>` (scope `mod`!).
3. Авторитет поколения: 4 кандидата; ровно одна уникальная полная пара, иначе conflict / missing; гибрид из половин запрещён.
4. Порядок ворот чтения (21 533): integrity → authority → generation → error → cancelled → absence (pending / error / canonical) → contract. При живой сводке
   отсутствие записи **канонично**; legacy допускается, только если сводки нет вовсе.
5. Жизненный цикл: ensure (смена поколения или перезапуск idle/stale/error/cancelled → чистое ведро) → commit (status=active, rev+1, digest='') → finalize
   (только active; ворота полноты по expectedEntityKeys × requiredMetricIds, pending/error блокируют, unavailable/unsupported допустимы) → done + digest.
   fail / cancel только из active того же поколения, частичные записи сохраняются, revision+1. Инвалидация: done→stale, словари не сжимаются. Списание: канонизация,
   печать сохраняется с новым digest.
6. Digest: FNV-1a32 по каноническому JSON `{schema, projectId, runId, status, revision, dictionaries, byEntityKey}`, сортировка ключей сущностей и метрик, ключи map
   сортируются localeCompare. Для совместимости хэш надо воспроизвести **бит в бит**: JS `JSON.stringify`, UTF-16 `charCodeAt`. Для NG без импорта старых сводок проще
   свой хэш.
7. Допуск при импорте (v628):
   | исходный статус | условие | итог |
   |---|---|---|
   | нет payload | — | idle, accepted-empty |
   | active / running / queued / pending | — | stale, quarantined-interrupted |
   | done | digest не совпал | error, quarantined-integrity |
   | done | авторитет conflict / missing | stale, quarantined-authority-* |
   | done | другое поколение | stale, quarantined-generation-mismatch |
   | done | контракт нарушен | error, quarantined-contract |
   | idle с данными | — | stale, quarantined-unsealed |
   | stale / error / cancelled | — | accepted-<status> |
   При любом изменении digest='', rev+1.
8. Типы контракта: integer = `Number.isInteger`; count = integer ≥0; bytes / duration = конечное ≥0; decimal = конечное; percent ∈ [0,100];
   boolean; enum = непустая строка; list = массив; map = простой объект.

**Вероятные ошибки и спорные места.**
- `ANALYSIS_METRIC_SUMMARY_VERSION_V599` не объявлен → самотест v626 падает с ReferenceError (22 049).

- commit в запечатанное (`done`) ведро без нового поколения тихо снимает печать (status=active, digest=''). Задумано это или нет — неясно.

- Сортировка `localeCompare` (ключи map, ничьи) зависит от локали; в NG брать бинарный порядок, а для паритета — фиксированную локаль.
