## 4. Для NG

**Переносить точно:**
1. **Планировщик трёх маршрутов** (133456): `unchanged` + полный физический индекс + все возможности + метрик-гейт → `FULL_REUSE`; не хватает
   возможностей → `INDEXED_ANALYSIS` (обход по индексу прошлого поколения, содержимое — точечно); иначе `FULL_SCAN`; отсутствие/нечитаемость
   артефактов прошлого поколения у `unchanged` → **блок до deep** (не тихий скан). Набор возможностей v7: `loosePaths, routeMetadataV2,
   archiveVirtualPaths*, archiveEntrySizesV555*, metrics, ddsVramV613, tags*, stickers*` (* — зависят от конфига).
2. **Инварианты перед promote** (как проверки, а не IDB-печати): (а) реестр staging = ровно текущие моды + overwrite, без дублей/лишних;
   (б) у каждого мода полный физический индекс, получены все недостающие возможности, ни одна прежняя не потеряна; (в) reuse-моды не попали
   в обход, scan/indexed — попали, счётчики плана = счётчикам печати; (г) сигнатуры staging = вычисленным; (д) конфликты: один финализатор,
   `contexts ≤ chains`, `chains=0 ⇒ contexts=0`, маппинги контекстов полные; (е) барьер `openTokens==0`, статус complete, ошибок 0.
3. **Порядок «после promote»** (134492–134549) и то, что ошибки после promote не откатывают поколение — в NG решить явно (сейчас часть шагов
   глотает ошибки warn-ом: нормализованный слой, жизненный цикл LG).
4. **Метрики reuse** (133004): атомарный carry-forward; метрики конфликтов и маршрута для reuse-мода всё равно пересчитываются. `fileCount =
   routeCount` (с виртуальными путями архивов), `physicalFileCount` отдельно; `sizeBytes = physicalBytes`.
5. **FNV-1a 32** (`hashStringToInt` 136021) — для совместимости id, оттенков, отпечатков (`toString(36).toUpperCase()`), иконок.
6. **Project Identity**: веса признаков цепочки (137840), формула проходов `min(10,(n−2)·2)`, 10 операторов имени, перцептивная уникальность
   цвета (OKLab, адаптивная `minDist = max(0.018, 0.07·sqrt(40/max(40,N+1)))`, 17 полос, золотой угол 137.508), круговое среднее цветов-источников
   (порог уверенности 0.22), emoji из 5 диапазонов, уникализация `"имя · FP4[-k]"`, **двухфазность** (внутренняя идентичность без коллизий,
   затем разрешение в отсортированном порядке) и **политика** `generate / preserve-manual / backfill-source / preserve-generated /
   regenerate-source-change / regenerate-collision` с блокировками полей. Это и есть «имена цепочек не прыгают между пробегами».
