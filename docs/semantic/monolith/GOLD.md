# Золотой фонд монолита

Идеи, которые монолит придумал и довёл до работы. Переносим **по смыслу**, а реализацию пишем заново
по правилам NG. Каждая строка ссылается на конспект с точными правилами.
Пополняется по ходу конспекта; пометка «владелец» значит, что идею отметил сам владелец.

Фиксация — это **план операций** (mkdir, backup, move_to_deleted, rename, rewrite_modlist…), pre-commit проверка с отпечатком набора записей, версия-бэкап и перенос удалённого в `deleted/`. | `pass/S03` (план, модалка из 5 шагов, `executeSyncCommitPlan`), `pass/S21` (карта операций, инварианты плана, CP5 issuance/phases), ADR 0006 | NG-D003. ## Что не переносим ни в каком виде

- Исполнение пользовательского кода через `new Function` с полным доступом к проекту: анализаторы логических групп
  (`pass/S04`), пользовательские пробеги (`pass/S10`), мета-блоки (`pass/S12`), «Копия ИИ» (`pass/S16`).
  Замена — песочница расширений (PHILOSOPHY «Эволюция»).
- Самотесты, которые проверяют исходный текст функций (`pass/S04`, `S11`, `S15`).
- Переопределение функций поверх себя (`structure.md`).
