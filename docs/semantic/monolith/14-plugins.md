# 14 — Плагины и эффекты (монолит → NG)

Прочитано по коду 2026-11-18 (клон монолита, `index.html`). Повод — замечание владельца: Claude смотрел на плагины
модоцентрично (мод «ждёт мастера», если хоть один его плагин без мастера), а у модов бывают необязательные
плагины-патчи. Задача — инструментарий плагинов как в монолите: одна правда, много проекций; состояния
складываются; индикатор показывает приоритет; синхронизация с переключателем мода-владельца; эффекты.

## 2. Состояния плагина

- **Несуществующий** (`isPluginNonexistent`): записи нет, запись вложенная (не в корне мода) или мод-владелец
  выключен. Монолит смешивал «мастера нет нигде» и «мод выключен» в одно чёрное состояние.
- **Владелец выключен** (`isPluginOwnerDisabled`): правда — живой `mod.enabled`; базовые мастера игры никогда.
- **Недостающие мастера** (`getPluginMissingMasters`): мастер (не в blacklist) без записи, несуществующий или
  `enabled === false`. Подсостояний не различал.
- **Переполнение** (`runtimeIndexOverflow`): full > `0xFD`, light > `0xFFF`.
- **Активация** (`getPluginStateText`): `skyrim-base` / `missing-dependency` / `foundling-nested` / `disabled` /
  `enabled` / `implicit-loadorder` / `owner-disabled` / `scan-only` **плюс диагностики через `+`** — по сути набор.

Приоритет цвета (`getPluginStateColorKey`): база — синий → несуществующий — чёрный → недостающий мастер — красный →
переполнение — жёлтый → скан — белый → зелёный.

**Почему «стакалось случайно».** Строка получала независимые классы: одна тема фона (`plugin-theme-*` — по
приоритету: skyrim / missing / problem / overflow / scan, иначе каста esl / esm / esp), `plugin-disabled`
(прозрачность и обесцвечивание — отдельно от темы), `has-missing-master` и `has-overflow` (цвет рамки —
отдельно). Три канала CSS — поэтому выключенный проблемный плагин в переполнении показывал всё сразу.
Точка — только приоритет.

## 3. Метка мода (индикатор-переключатель)

`getModPluginIndicatorBucket`: по плагинам мода (не blacklist, не вложенные) красный — сразу, иначе
жёлтый > esm > esp > esl, пусто — `empty`. Цвета: выключен `#475569`, красный `#ef4444`, жёлтый `#f59e0b`,
esm `#22c55e`, esp `#84cc16`, esl `#38bdf8`, без плагинов `#5f8f6b`. Гейт — эффект «Индикатор» и его
`pluginColors`. **Модоцентрично:** любой плагин без мастера красит мод, включая необязательные патчи.

## 4. Синхронизация с модом-владельцем

`togglePluginEnabledByName`: плагин, чей мод выключен, включается вместе с модом (`setPluginOwnerModEnabled`);
несуществующий — не включается; иначе отметка переворачивается. Выключение мода делает его плагины
«владелец выключен» без записи — производное. Каскад (`enablePluginsCascadeByDependencies`): слои от базы вверх,
только тот, у кого все мастера уже включены; owner-disabled и missing не трогаются.

## 5. Версии из перезаписи файлов

`applyPluginOverwriteVersions`: экземпляры одного имени — группа; победитель — у включённого владельца с большим
приоритетом (`pickPluginOverwriteWinner`); остальные — `overwritten`. Проблема монолита — факты (мастера, флаги)
брались не всегда от победителя.

## 6. Окно плагинов

Блок: строка статистики (merged, mo2, instances, overwrite groups, blacklisted, full / light и переполнение),
тулбар (поиск, белый скан, копировать, blacklist, каскад), касты, сортировка; рабочая область — весь список
(`kind`, `masters:dependents`, порядок / индекс), карточки модов-владельцев выбранного плагина, мастера,
зависимые. Alt+клик или клик по точке — переключить; правый клик — в blacklist.

## 7. Эффекты

`tags`, `badges`, `statistics`, `counter`, `indicator`, `hoverCloud`, `colorFocus`. У каждого `enabled` и свои
настройки (`normalizeEffectSettings` с границами), хранение — `project.ui.effectSettings`. Блок метаинфы:
переключатель на эффект + раскрытие: описание, сводка, настройки (`renderSettings` эффекта). Применение —
атрибуты `body[data-*]` и CSS-переменные.

## 8. В Satellite (2026-11-18)

- Правда: `@sat:plugins.list`; состояния — **набор** `PluginState` (`@sat:plugins.states`): призрак (имя в списках,
  файла нет), моды выключены, игнор, нет мастера — три подсостояния (такого нет / в выключенном моде / выключен),
  переполнение, выключен, нет в списках MO2, несколько копий; цвет — первый цветной; каста esm / esp / esl;
  мастера, которых нет нигде, — призраки (`PluginList::ghosts`). Версии — факты всегда от победителя
  (`@sat:plugins.versions`).
- Метка мода — **плагиноцентрично** (`@sat:plugins.mod-mark`): приоритет только от плагинов, которые грузятся;
  снятый плагин без мастера — «необязательный патч» в стопке; мастер из того же мода не недостающий.
- Наложение — намеренно, каждое состояние своим каналом (заливка, вуаль, прозрачность, левая и правая кромки,
  контур, бейдж), индикатор — приоритет и кольцо остальных (`apps/devserver`, раздел «plugins»).
- Проекции одной правды: окно «Плагины», блок мода, индикатор, облачко, фокус-группы (`@sat:app.plugins`,
  `@sat:app.focus`). Синхронизация — команда `SetPluginChecked` включает мод-владельца (`@sat:app.plugins-edit`).
- Эффекты — `@sat:effects` в проекте, блок «Эффекты» в окне (`@sat:app.effects`).
