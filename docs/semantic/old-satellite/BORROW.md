# Старый Satellite → NG: что берём

Сводка конспекта `00-conspectus.md`. Каждая строка — принцип или контракт, у которого будет **один владелец** в NG
(после формализации ядра — в `docs/semantic/MAP.md`).

## Принципы (дословно из прототипа, остаются законом)

1. **Истина одна, проекций много.** UI наблюдает проекции, истиной владеет логика (`no-ui-state-as-truth`).
2. **Идентичность — id, не имя** (`stable-id-only`). Имя — отображение; одинаковые имена — разные сущности.
3. **Команды не вызывают рендер** (`no-render-from-command`): изменение → инвалидация → один пересчёт на кадр.
4. **Хранение ≠ runtime** (`storage-not-runtime`): производное не хранится, после загрузки пересобирается.
5. **Новые возможности — только через ресурсный путь** (`manifest → registry → policy → runtime`).
6. **Проверка архитектуры при старте, загрузке и регистрации** (`guarded-runtime`).
7. **События не владеют истиной**, только уведомляют.
8. **Ресурс не трогает истину напрямую**: читает копии через API, пишет только командами.
9. **Стадию вызывает только оркестратор**; стадии возвращают факты.

## Контракты и механизмы

| Из прототипа | В NG | Куда |
|---|---|---|
| Реестр ресурсов по видам (примитивы, обёртки, рендереры, команды, клавиши, UI-варианты, задачи, импортёры, валидаторы, пресеты) | Единый реестр ресурсов с типизированными видами; встроенное регистрируется так же, как расширения | ядро ресурсов (формализация) |
| Манифест — единица расширения; «зарегистрировано» ≠ «активно в проекте» | То же; id ресурса = `<манифест>/<локальный id>`; зависимости проверяются | ядро ресурсов |
| Уровни доверия core / preset / project / external, deny-by-default, одобрения, причина отказа как данные | То же, но доверие — от **источника загрузки**, возможности — **на ресурс**, одобрение — на машине по хешу | политика (ADR 0007 п.7) |
| Ограниченный runtime API ресурса | API ядра по возможностям; песочница WASM для кода | Фаза 3.5 |
| Клавиша = ресурс `{combo, scope, priority, when, commandId}` | Раскладка курсора ADR 0008 — клавиши-ресурсы по умолчанию | интерфейс + ядро ресурсов |
| Команда: политика → `canRun` → выполнение / задача → журнал → объявленная инвалидация | Команды ядра; что они меняют — известно, зависимые проекции инвалидирует граф | ядро |
| Задачи: очередь, отмена, прогресс, события | Задачи NG-D003 + поколения `run::Authority` | NG-D003 |
| Грани мода (`contextDescriptors`: files, plugins, overwrite, scripts…; значок на строке, секция меты, тяжёлое хранилище) | Реестр граней; поставщики — анализаторы; счётчики карточки и секции меты — грани | ядро данных |
| Пакет строки (`counters`, `badges`, `techTags`, `stickers`, `conflictStrip`) | `Row` ядра + значения граней для видимого окна | ядро + интерфейс |
| Кружок-состояние как UI-вариант (enabled / disabled / unmanaged / locked / representative) | Состояние → вариант — данные | интерфейс |
| Флаги сущности `unmanaged, locked, movable, pseudo, officialDlc` + `sourceRef` (откуда пришла) | Атрибуты сущности канона + происхождение | канон |
| SYNC как долги между базовым снимком и желаемым состоянием | История книги + `manager_diff` → план фиксации | NG-D003 |
| Стадии пробега с `requires / provides` по ключам фактов, план из графа, барьеры доступа с резолверами | Контракт анализаторов NG дополнить зависимостями по фактам; барьер `routes.complete` | NG-D002 |
| «В проекте — сводки и ссылки, сырые маршруты — в индексе» | Холодный ярус + контейнер (ADR 0007) | хранение |
| Карта архитектуры как данные + `architectureGuard` | Семантический слой: карта + якоря в коде + проверка в CI | семантический слой |
| Окна: род = обёртка; magnet / dock (сектор стороны); холст; isolated / shared выделение | ADR 0009: виды, каналы данных групп, дерево dock, граф magnet | ADR 0009 |
| Пресеты: ядро + игра (Skyrim, Fallout 4) + менеджер (MO2) | Стек пресетов = core + game pack + manager adapter | Фаза 4 |
| Пакет контекста для ИИ + фабрика расширений + предпросмотр + одобрение; UI DSL | Developer Center NG; UI-расширения — только DSL (данные) | Фаза 3.5 |

## Не повторяем (дефекты прототипа)

- Доверие по префиксу id; поля определения перетирают нормализованные; источник ресурса переопределяется
  внутри манифеста; нет пространств имён — повышение доверия и тихая подмена ресурсов.
- Возможности глобальны на проект, `requestedCapabilities` не проверяются.
- Одобрение хранится в ресурсе и в файле проекта; `new Function` в главном потоке; фабрика исполняется до
  одобрения; шаблоны в `innerHTML`.
- Позиции (`order.global`) хранятся в сущностях; перемещение O(n·k); проекция окна пересобирается целиком.
- Изменение выделения грязнит все окна; состояние окон конфликтов и файлов глобально на проект.
- `commitDock` теряет группу; `concurrencyKey` задач не работает; у задач нет поколений; `hashText` — не FNV.
- Три независимых источника правды о плагинах без канона (вероятная «ловушка версионности»).
