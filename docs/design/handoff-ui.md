# Бриф для дизайна окна Satellite NG (передача во внешнюю модель)

Задача: перерисовать главное окно Satellite NG — менеджера модов Skyrim поверх Mod Organizer 2 — в языке
«UI Laboratory v7» владельца (файл `Satellite_UI_Laboratory_v7.html`). Целевая композиция — раздел лаборатории
**06B «Модлист как рабочее пространство»** (`#ide-lab`, прототип `v6-app`): шапка с индикаторами сборки, тулбар с
зубным переключателем вида, тихие кнопки, «i»-гайды, фокус-группы. Синий акцент, обе темы.

## Что приложено

| Файл | Что это |
|---|---|
| `index.html` | Живое окно целиком: один файл, CSS + разметка + ванильный JS, без сборки и фреймворков. Это то, что надо переделать. |
| `frozen-main.html` | Снимок отрисованного окна (DOM после загрузки, скрипты вырезаны): видно реальную разметку строк, бейджей, блоков. Открывается в браузере как статика — удобно править CSS. |
| `current-*.png` | Как окно выглядит сейчас (тёмная, светлая, фокус на моде). |
| `Satellite_UI_Laboratory_v7.html` | Лаборатория владельца — основа дизайна. |
| `adr-0020-interface-direction.md` | Решения по интерфейсу: роды контролов, текст, курсор, хедер, контейнер мода, метаинфа, карточки цепочек. |

## Как устроено окно (нельзя ломать)

- Окно ничего не решает само: ядро (Rust) — источник правды, окно шлёт `query` / `command` на сервер и рисует ответ.
- **Список модов виртуальный.** Позицию и размер каждого элемента считает ядро; JS ставит их `transform: translate(x,y)`,
  `width`, `height` (функция `sync()`). Строки — `position:absolute` внутри `#layer`. Нельзя переводить список на
  flex/grid-поток — только оформление внутри элемента `.row`.
- **Кирпичики меряют сами себя** (`brickMeasures()`): окно создаёт скрытый образец строки с классами
  `.row .lead .toggle .name .cnt .strip .ctx .ico` и `.ctx > b`, `.ctx i` и меряет шрифт имени, бейджи, счётчики,
  отступы. Эти классы и структура внутри `.row` должны остаться (можно менять стили — замеры подстроятся сами).
- Разметку строк, бейджей, блоков метаинфы, модалок пишет JS (функции `paint()`, `strip()`, `detail()`, `totals()`,
  `tiles()` и др.). Менять HTML-шаблоны в этих функциях можно, если сохраняются id и `data-*` атрибуты, которые
  читает код.
- **id, которые читает JS** (не переименовывать, не удалять):
  `advApply advClose advStrict advTruth bConf bDecor bMod bPlug bPrev bTree badgeModel ccQ cols ct ctAbout ctAdv
  ctAdvBtn ctCanvas ctCards ctClose ctCtx ctLegend ctList ctOrder ctScroll ctSpacer ctStack ctStackClose ctStats
  ctStatus ctTabs ctTitle ctView ctx ctxFilter density err filter fx fxBtn fxClose fxModes fxPinBtn fxPrev fxQ
  fxSubj fxTree fxView layer list modcount palette passBtn passDot passPanel peK peS peV projState rec recBtn
  recClose recList recOnly recPlugin recStats saveBtn sepcount spacer stats sy syBody syClose syCommit syFoot syInfo
  sySurface syncBtn syncDot theme tiles`.
  `#cols` — зубной переключатель: кнопки с `data-v="-1|340|0"`, активная получает класс `on`.
- Тема — `data-theme="light"` на `<html>`; переменные цвета в `:root` и `:root[data-theme="light"]`.
- Внешних зависимостей нет и не нужно (никаких CDN, шрифтов из сети): окно работает офлайн.

## Предметные правила (от владельца)

**Канон порядка.** Список вертикальный: строки сверху вниз, в строке может быть несколько модов — слева направо.
Порядок читается по индикаторам (кружок вкл/выкл слева): они стабильны и держат линию строки.

**Вид по умолчанию — кирпичики.** Однострочные контейнеры модов, несколько в строке, **без зазоров и без скруглений**;
соседи делят одну линию контура. Пустая строка (вертикальный запас) — перед каждым разделителем.

**Контейнер мода — как CSS контейнера монолита:**
- прозрачный, без фона, тонкий контур;
- ширина задаётся именем, общий минимум ≈ 50 px;
- имя по центру, при нехватке места перекрывается (обрезается);
- индикатор у левого края; бейджи конфликтов справа от индикатора;
- счётчики (W/L/M/+N, esp, X) у правого края, копятся влево, при столкновении перекрывают имя;
- в однострочном контейнере **всё на одной высоте**; когда контейнер растянут — индикатор к левому верхнему углу,
  счётчики к правому нижнему, имя в центре;
- теги — полоски по контуру;
- стикеры — ярлыки чуть выше левого верхнего угла, копятся вправо; и каждый стикер даёт **свой контур вокруг
  контейнера**, контуры наслаиваются слоями (сейчас — inset-кольца `box-shadow`).

**Роды контролов** (ADR 0020 §1): режим (один из N) — зубной сегментный переключатель; действие — кнопка-иконка, главное
— акцентом, прочие призрачные; данные из ядра (централи конфликтов, теги, стикеры) — чипы с числом и цветом своего
рода, не кнопки; включатель блока — кружок в углу блока.

**Текст.** Никаких пояснительных фраз в интерфейсе. Подписи — одно-два слова. Объяснения — гайд-модалка по маленькой
слабовидимой «i» в углу контекста.

**Шапка.** Слева знак и конвейер «Пробег → Конфликты → Sync» со статус-точками. Справа — индикаторы сборки
(только то, что требует внимания), по наведению — полный список. Нижней строки нет.

**Метаинфа (правая колонка)** — блоки с кружком-включателем: сверху постоянный «Выделение» (перечень выделенных,
счётчики тегов/стикеров, суммы), затем Мод, Конфликты, Плагины, Доноры, Буфер (области), Декор, Теги, Стикеры,
Заметки, Дерево.

**Курсор клавиатуры** — рамка-прицел, выделения не меняет; выделение — заливка.

**Смысловые цвета** (выигрывает / проигрывает / середина / не виден) — отдельно от акцента.
