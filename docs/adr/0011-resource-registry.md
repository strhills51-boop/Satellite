# ADR 0011 — Реестр ресурсов: манифест, источник, возможности, одобрения, клавиши

- Статус: **принято** (2026-11-01), направление владельца: «реестр ресурсов по исправленной модели прототипа»
- Связано: ADR 0010 (закон 10 «расширение — ресурс»), ADR 0009 (окна и поставщики фокус-групп как ресурсы),
  ADR 0008 (раскладка клавиш курсора), `docs/semantic/old-satellite/BORROW.md` (дефекты прототипа)
- Код: `sat-core::resource` (`@sat:resource`), запуск команд — `Session::run` (`@sat:session`)

## Что берём из прототипа и что исправляем

Прототип «Satellite V2 Constructor Core» правильно сделал путь `manifest → registry → policy → runtime` и
встроенное, зарегистрированное так же, как расширения. Ошибки, которые NG исключает **устройством**, а не
соглашением:

| Прототип | NG |
|---|---|
| Доверие по префиксу id (`core.*` — своё) | Доверие только по **источнику загрузки** (`Source`): встроенное / машина / проект / сеть. Id — имя, не пропуск |
| Возможности на проект целиком | Возможности **на ресурс**, ровно те, что он объявил; рантайм проверяет при каждом запуске |
| `approvedResourceIds` в файле проекта | Одобрения **на машине пользователя** (`approvals.json` в профиле), привязаны к id + версии + дайджесту манифеста. Чужой проект не может ничего себе разрешить |
| `new Function` для пользовательских ресурсов | Манифест — **данные**: род (`Kind`) и параметры. Поведение — встроенные операции (`op`) |

## Решение

- **Манифест** `{format, id, version, kind, title, requires, depends, params}`. Роды: команда, клавиша, окно,
  анализатор, поставщик фокус-групп, пресет. Id — `namespace.name` строчными.
- **Источник → доверие.** Встроенное активно с тем, что объявило. Остальное активно, только если одобрение на
  машине покрывает все объявленные возможности для этого id, версии и дайджеста; иначе `NeedsApproval(чего не
  хватает)`. Ресурс без возможностей (чистые данные) активен сразу.
- **Зависимости.** Активный ресурс, у которого зависимость не активна, — `Blocked` (до неподвижной точки).
  Клавиша зависит от своей команды, поэтому клавиша на неодобренную команду не «молча мертва», а видно, почему.
- **Встроенное не затеняется.** Id встроенного нельзя перерегистрировать; ресурс машины или проекта
  обновляется только из того же источника.
- **Возможности:** чтение канона / декораций / фактов, запись декораций, запись канона, чтение файлов, задачи,
  сеть. Опасные (меняют то, что уходит в менеджер, или выходят с машины) — запись канона, задачи, сеть.
- **Команды.** `op` — словарь встроенных операций (навигация, сдвиг выделения, переключение, свёртка,
  вкл/выкл). Операция сама объявляет, что ей нужно (`Action::needs`); `authorize` проверяет, что ресурс активен и
  ему это выдано. Запуск — `Session::run(registry, id, view)`, дальше обычный путь команды → набор изменений →
  граф.
- **Клавиши.** Аккорд в каноническом виде (`Ctrl+Alt+Shift+Meta+Key`), контекст (`list`, `global`), команда или
  `-` (снять). Карта клавиш: побеждает источник с большим приоритетом (машина > проект > сеть > встроенное);
  ничья на вершине — **конфликт**, аккорд не назначается, пока пользователь не решит. Раскладка курсора
  ADR 0008 — 28 встроенных клавиш-ресурсов.

## Что дальше

- Окна, поставщики фокус-групп и анализаторы как роды ресурсов (сейчас валидируются только клавиши).
- Хранилище ресурсов машины (папка профиля) и загрузка ресурсов из контейнера проекта (ADR 0007).
- UI одобрений: список `Registry::pending()` с объявленными возможностями, опасные выделены.
- Настройки как вид истины (ADR 0010): реестр и одобрения — их первые владельцы.
