# ADR 0005 — Работа дистанциями с контрактом закрытия

- Статус: **принято** (2026-10-30)
- Связано: PHILOSOPHY §9, протокол VibeGo (VIBE_STATE)

## Решение

Любая работа крупнее одной правки ведётся как **дистанция** — файл `docs/distances/NG-DNNN-<slug>.md`:

```markdown
# NG-DNNN — Название
- Статус: open | closed | abandoned
- Пункты карты: PHILOSOPHY §8 …
## Цель
## Контракт закрытия      ← проверяемые факты: тесты, бенчмарки, скриншоты, данные API
## Вне рамок               ← что сознательно не делаем
## Решения                 ← решение + причина
## Находки и риски
## Доказательства закрытия ← команды и их результаты
## Следующий фокус
```

Правила:
1. Дистанция закрывается только когда **каждый** пункт контракта подтверждён фактом из раздела «Доказательства».
2. Если по ходу контракт оказался неверным — меняем контракт явно, с причиной, а не тихо.
3. В том же коммите, где дистанция закрывается, отмечаются чекбоксы в PHILOSOPHY §8.
4. Паритет с монолитом доказывается наблюдаемым поведением, а не сходством исходников.
