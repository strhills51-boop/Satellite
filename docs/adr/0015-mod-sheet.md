# ADR 0015 — Карточка мода: стандарт быстрого обзора

- Статус: **предложено** (2026-11-01), идея владельца («мини-листинг, стандарт быстрого обзора мода, лениво
  подгружается при выделении или в облачке»)
- Связано: ADR 0007 (`.stll` самостоятелен), 0013 (метрики, теги), 0014 (файлы); PHILOSOPHY «Модель сервиса»
  (манифест автора `satellite.yaml`), «Указатели», «Спутник»

## Решение (направление)

**Одна схема карточки** — и в окне (облачко, сводка), и на сайте (листинг), и в манифесте автора. Карточка не
хранится целиком: она **собирается из слоёв**, у каждого раздела — происхождение и свежесть.

| Слой | Откуда | Что | Когда есть |
|---|---|---|---|
| Наблюдённое | факты скана в проекте | размер, файлы, плагины и их состояние, метрики, найденные теги, роды конфликтов | всегда, без сети |
| Пользователя | проект | заметка, свои теги и стикеры, решения, намерения | всегда |
| Автора / сообщества | представление мода с сайта или `satellite.yaml` из архива | название, автор, краткое описание, версия, требования, известные конфликты и патчи, источники (Nexus, Patreon…), превью | после подгрузки; копия хранится в `.stll` для работы вне сети |

Уровни показа — одна схема, разная глубина:
- **значок** (строка списка, плитка): имя, 1–2 сигнала (не виден в игре, нет мастера, новый);
- **мини** (облачко, сводка): то, что владелец назвал мини-листингом — слои кратко, по разделу на строку;
- **полный** (листинг на сайте, отдельное окно).

Правила:
- **Лениво и по разделам.** Запрос карточки отдаёт сразу то, что есть локально; разделы автора и сообщества
  приходят позже событием («карточка дополнилась»), окно перерисовывает только их. Выделение мода не ждёт сети.
- **Происхождение у каждого утверждения** («заявлено автором» / «наблюдается в N сборках» / «наблюдено у тебя»):
  расхождение слоёв видно («автор пишет — нужен SKSE, а у тебя DLL нет»).
- **Привязка к внешнему моду — через внешнюю идентичность сущности** (ADR 0007: Nexus id, хеши файлов, версия);
  без неё карточка состоит из наблюдённого и пользовательского слоёв.
- Разделы карточки — расширяемые (вид-расширение может добавить раздел, ADR 0011).

## Порядок работ

1. Схема `ModSheet` с разделами и происхождением; `Query::ModSheet { key, level }` из наблюдённого и
   пользовательского слоёв (после шага 2 ADR 0007 — факты в проекте).
2. Раздел внешней идентичности и копия представления автора в `.stll`; формат `satellite.yaml` — та же схема.
3. Ленивое дополнение по событию; окно: облачко и сводка.

## Сделано

- Шаг 1 (2026-11-01): `sat-app::sheet` (`@sat:app.sheet`) — схема 1: карточка = разделы полей, у раздела
  происхождение (`observed` / `user`; `author`, `community` — в схеме, данных пока нет), у поля стабильный id,
  значение (`count`, `bytes`, `flag`, `text`, `names`) и необязательный сигнал (`note` / `warn` / `problem`).
  Разделы: `content` (размер, файлы, архивы, плагины, DDS и VRAM, NIF, PEX, HKX, DLL, исходники; сигналы «нет
  папки», «ошибка скана», «пуст», вложенные архивы), `conflicts` (W/L/M/уникальные, цепочки и сколько решено;
  «не виден в игре» — всё перекрыто, «есть нерешённые цепочки»), `plugins` (включены / выключены / скрыты,
  недостающие мастера; «плагины мода выключены, а мод включён»), `user` (вкл., теги, стикеры, заметка).
  Уровни: значок — до двух сильнейших сигналов; мини — по 6 полей на раздел, сигналы первыми, нули опущены;
  полная — всё. `Query::ModSheet { key, level }`. Подписей нет: окно подписывает поле по id. Факты мода, не
  ставшие путями (метрики, «нет папки», ошибка), таблица теперь хранит рядом с путями (`@sat:table.summary`).
  Окно карточку пока не показывает — это работа над интерфейсом вместе с владельцем.
- Шаг 2, первая часть (2026-11-02): **источник мода** (`@sat:source`, раздел проекта `sources` по id сущности) — то,
  что MO2 записал в `meta.ini`: сайт, игра, id на Nexus, версия, новейшая известная версия, файл установки, ссылка
  (`link()` — страница Nexus по игре и id). `sat-cli analyze` читает `meta.ini` всех модов параллельно (на
  синтетической сборке — 9 мс); вне сборки — из проекта. В карточке — раздел `source` (сигнал «есть обновление»),
  в выражениях — метрики `nexus_id`, `update` (`update` в `--find`, в стикерах и счётчиках). **Ещё нет:** копия
  представления автора с сайта, `satellite.yaml`.
